📝 学习笔记：Tailscale 与 ClashShell

1. Tailscale：异地组网神器

🟢 它是做什么的？

Tailscale 是一个基于 WireGuard 协议的虚拟组网工具。简单来说，它能把处于世界各地、不同网络环境下的设备（手机、家里电脑、云服务器），通过软件“拉”到一个虚拟的局域网里。

⚡️ 核心优势

  • 无需公网 IP：不需要向运营商申请公网 IP，也不需要动路由器的端口映射（NAT 穿透能力极强）。
  • 零配置（Zero Config）：不需要复杂的密钥交换，登录同一个账号就能互连。
  • 安全性高：点对点加密传输。

🛠 我的应用场景

  • 远程管理：在外面的网络（如公司、4G）直接访问家里的 青龙面板 或服务器，就像在家里连 WiFi 一样。
  • 访问内网服务：直接通过 Tailscale 分配的 IP（通常是 100.x.x.x）SSH 连入服务器，不再需要暴露高危端口到公网。

备忘命令：

  • 启动：sudo tailscale up
  • 查看状态：tailscale status
  • 获取 IP：tailscale ip -4

2. ClashShell：终端网络代理

🔵 它是做什么的？

注：ClashShell 通常指在 Linux 终端（Shell）环境下运行的 Clash 核心或其管理脚本。

它是服务器端的“网络出国”工具。不同于 Windows/Mac 上有图形界面的 Clash，服务器端通常只有黑框框（命令行），ClashShell 就是让服务器也能顺畅访问 GitHub、Docker Hub 等外部资源的工具。

⚡️ 核心作用

解决服务器/青龙面板在拉取脚本、安装依赖时出现的网络报错，例如：

  • connect ECONNREFUSED
  • Download failed
  • git clone 速度极慢或超时

⚙️ 关键配置 (环境变量)

在 Linux 终端中，光运行 Clash 是不够的，还需要告诉系统去使用这个代理。通常通过设置环境变量来实现：

# 开启代理 (端口需根据配置文件调整，常见为 7890)
export http_proxy="[http://127.0.0.1:7890](http://127.0.0.1:7890)"
export https_proxy="[http://127.0.0.1:7890](http://127.0.0.1:7890)"

# 关闭代理
unset http_proxy
unset https_proxy
